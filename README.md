# صلاتي — مواعيد وتذكير الصلاة في مصر (Salati PWA)

**Live Web App:** https://abysswatcher2.github.io/salati-prayer-time/

تطبيق ويب تقدمي (PWA) يعمل أوفلاين، مصمم للالتزام بالصلاة بالمواعيد المصرية الرسمية، مع تذكير مستمر كل ربع ساعة حتى بعد انتهاء وقت الصلاة إلى أن تؤكد صلاتك في القائمة.

---

## المميزات الرئيسية / Key Features

- **المواعيد المصرية الرسمية:** حساب المواقيت وفقاً للهيئة المصرية العامة للمساحة لجميع **27 محافظة مصرية** مع دعم تحديد الموقع التلقائي (GPS) وضبط الدقائق يدوياً.
- **تذكير مستمر كل ربع ساعة:** يبدأ التنبيه عند دخول وقت الصلاة ويستمر كل 15 دقيقة (أو حسب اختيارك) حتى بعد خروج وقت الصلاة، ولا يتوقف إلا عند الضغط على **«الْحَمْدُ لِلَّهِ، صليت ✓»**.
- **قائمة صلوات اليوم (Checklist):** متابعة حالة كل صلاة (الْفَجْر، الشُّرُوق، الظُّهْر، الْعَصْر، الْمَغْرِب، الْعِشَاء) مع عداد تنازلي للصلاة القادمة وساعة وتاريخ ميلادي وهجري لحظي.
- **جدول مواعيد مصر:** جدول تفصيلي لمواقيت اليوم بالإضافة إلى جدول 7 أيام و30 يوماً قادمة.
- **سجل الالتزام:** متابعة إنجاز آخر 7 أيام وسلسلة الأيام المتتالية (Streak) — تحفظ جميع البيانات محلياً على جهازك.
- **متوافق مع كل الهواتف:** يعمل على هواتف **أندرويد** و**آيفون (iPhone / iOS)** ويدعم التثبيت على الشاشة الرئيسية.

---

## التثبيت على الهاتف / Mobile Installation

### أندرويد (Android - Chrome)
1. افتح الرابط: https://abysswatcher2.github.io/salati-prayer-time/
2. اضغط قائمة **⋮** ثم **إضافة إلى الشاشة الرئيسية (Add to Home Screen)**.
3. فعّل إشعارات الهاتف واجعل التطبيق أو Chrome **بلا قيود** في إعدادات البطارية لاستمرار التذكير في الخلفية.

### آيفون (iPhone - Safari)
1. افتح الرابط في **Safari**: https://abysswatcher2.github.io/salati-prayer-time/
2. اضغط زر المشاركة **Share** ثم **إضافة إلى الشاشة الرئيسية (Add to Home Screen)**.
3. افتح التطبيق من أيقونته على الشاشة الرئيسية واضغط **«تفعيل إشعارات الهاتف»** (مدعومة على iOS 16.4 فأحدث).

## التشغيل والتطوير محلياً / Local Development

```bash
npm install
npm run dev      # Start local server (http://localhost:5173)
npm test         # Run unit tests (Vitest)
npm run build    # Production build to dist/
```
